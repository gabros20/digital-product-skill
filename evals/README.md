# Evals — digital-product

Four suites, repository-only (never installed with the skill):

- `activation/` — should the composer trigger at all; negatives are single-domain prompts that
  belong straight to a specialist pack, plus multi-agent-topology prompts that belong to
  `orchestrate`.
- `traversal/` — given a composer prompt, which references must (and must not) be loaded.
- `output/` — behavioral contracts: dated seam rulings cited correctly, contested seams relayed
  unadjudicated, minimal-path subtraction, ledger discipline, coordination-mode discipline.
- `compression-ablation/` — the clusters whose removal must visibly degrade behavior: the
  subtraction rule, the seam registry, and mode discipline.

Prompts deliberately voice user confusions (e.g. asking the composer to settle a contested seam,
or to parallelize everything); the assertions define the disciplined response.
